# NeoPixel-VU-meter
This is a repository for Hackclub's event, Half-Life. NeoPixel VU meter is a volume unit meter made during week 4 of Half-Life.

The microcontroller it will use is the Seeeduino XIAO RP2040.
The microphone it will use is the MAX4466.
The LEDs it will use are the NeoPixel Stick - 8 x 5050 RGB LED with Integrated Drivers.
