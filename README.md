# NeoPixel-VU-meter
This is a repository for Hackclub's event, Half-Life. NeoPixel VU meter is a volume unit meter made during week 4 of Half-Life.

The microcontroller it will use is the Seeeduino XIAO RP2040.
The microphone it will use is the MAX4466.
The LEDs it will use are the NeoPixel Stick - 8 x 5050 RGB LEDs with Integrated Drivers.

I made this project's PCB in KiCad, and the Firmware in Arduino IDE.

There are steps that help you with what to do after getting the components to tune your meter. Before that, though, in Arduino IDE, you will need the Adafruit NeoPixel Library (https://github.com/adafruit/Adafruit_NeoPixel) and the Raspberry Pi Pico/RP2040/RP2350 board in the Boards Manager. After getting these, you will need to select the Seeed Xiao RP2040 Board in the IDE.
